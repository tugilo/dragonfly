## 4. エデュケーションコーナー（横山尚武）

**テーマ:** 事業を広げる時に重要なのは商品じゃない

| 観点 | 内容 |
|------|------|
| **課題** | 売上が伸び悩む原因は商品不足より **先入観（固定観念）**。自社商品・顧客像の前提が強いほど、新しいチャンスを見逃しやすい |
| **処方** | 新商品開発ではなく、**売り方**と**売る相手**を変える。商品はそのままでも、誰にどう届けるかで事業が広がる |
| **実例** | 横山さん自身は当初 AI 社員を1社ずつ直接提供。BNI でパートナーを組むと「不動産特化型」「サロン特化型」など複数モデルへ展開できた |
| **A+B+C+D=11** | 自分以外に4人のパートナーを探すと、11通りの事業パターンが組める、という話（組み合わせの定義は要約のみ） |
| **今週の問い** | 「あなたの商品は誰と組むことでスケールするか」。同じ顧客に別商品を届ける人／相談を受ける人／顧客が集まる場を持つ人を探す |
| **結論** | BNI は人と話すことで先入観を解き、ビジネスをスケールさせる場 |

## 6. メインプレゼンテーション

### 山口薫 — 中古スマホ買取販売

**テーマ:** 社用スマホ・タブレットの法人一括買取

| 観点 | 内容 |
|------|------|
| **拠点** | 秋葉原。スマホ・タブレット・PC の法人買取。精密修理で、他社がジャンク扱いする重度破損もパーツ単位で査定 |
| **企業の課題** | データ消去への不安と手続きの手間で、何十台・何百台が倉庫に放置されやすい |
| **実例** | iPhone 背面が大きく割れた端末も買取実績あり。iPhone SE 第2世代は1台 **3,000円** で買取、という説明 |
| **選ばれる理由** | ①数台〜100台の一括対応 ②検品後の即日振込 ③専門知識によるデータ消去 |
| **流れ** | 相談 → 概算 → 秋葉原へ送付 → 動作確認・データ消去 → 納得後即日振込 |
| **金の卵** | 総務部長・IT担当・コスト削減に関心の高い経営者。全社スマホ入替予定、オフィス移転で古い端末が出る企業 |
| **紹介トリガー** | 「社用スマホを入れ替える」「倉庫に昔の社用携帯がある」→ データ安全・まとめて即現金化できる秋葉原のプロを紹介 |

### 渡邊真大 — 着物に強い出張買取

**テーマ:** 着物から家まるごと買取（要約「渡辺真央」は誤記）

| 観点 | 内容 |
|------|------|
| **プロフィール** | 福岡県北九州市出身、横浜在住7年目。買取はバイセル3年＋独立3年で計6年目。口コミサイト2,000社中1位、という説明 |
| **動機** | 7月に2人目の娘が誕生。「娘にパパの仕事を誇りに持ってもらいたい」 |
| **強み** | 着物は年間約10,000枚を見て1点ずつ市場価値を出せる。カテゴリー名で着物限定に見えがちだが、**家まるごと買取**が本領 |
| **クイズ** | タワーマンション vs 築50年の家、不用品買取が高いのはどちらか → **築50年**（着物・骨董・アクセサリーが残りやすい） |
| **BNI経由の実例** | 都内で捨てる予定の家具・家電・ゴルフ用品など4トントラック1台＋ハイエース1台分を引き取り、買取 **200万円**。残置物処分は見積150万円 → 50万円（100万円削減）。手元は −150万円予定が **+150万円** に逆転 |
| **高く買える理由** | ネット直販と海外輸出で中間マージンを抑える |
| **建設・不動産への順** | 先に買取査定 → 価値あるものを抜く → 残置物撤去・解体・売却。処分費用と量を減らし、顧客満足を上げる |
| **紹介合図** | ①売りたい前に家を空にしたい ②残置物の処分費用が高い ③相続した空き家が片付かない |
| **エリア** | 出張買取は関東圏中心。宅配買取なら全国 |
