### 2.3 横山セッション: クロスセルビジネス戦略

#### 2.3.1 BNI 活用フェーズの変遷

| フェーズ | 内容 |
|----------|------|
| **入会初期** | 誰が何をしているか情報が少なく、**紹介をもらうこと**だけを目標に設定。依頼が来たら何でも対応するスタンス |
| **転換点（2026年6月頃）** | 「**一緒に何かを作る**」感覚に切り替えてから商談展開スピードが向上。苦手・不足を補い合えるメンバーとの出会いが、事業の視野と速度感を変えた |
| **現在** | 小中貴晃と共同で **AI 事業支援会社（要約「パスソール」・表記要確認）を 2026-09-29 に創業**。設立 1 ヶ月弱で複数の顧客・取引先が生まれている |

#### 2.3.2 クロスセルビジネスの核心

| 論点 | 内容 |
|------|------|
| **商品の賞味期限** | 去年通用した商品が今年同じ価格で売れるとは限らない。AI 台頭により自分のサービスを「**良い意味で破壊・再構築**」し続ける必要がある |
| **複数商品の重要性** | 売上規模の大きい日本企業は必ず複数のコンテンツを持つ（例: 光通信 — 営業力 × 他社商品で子会社を次々設立）。BNI メンバーを「**仲間であり一つの商品**」として捉えると、提案力が **組み合わせの数**だけ増える |
| **PMF の応用** | 新しい市場に一から商品を合わせるのは難しいが、**誰かと組む**ことで既存商品を別市場に適合させやすくなる |
| **具体例（AI 社員派遣）** | AI 教育単体は競合過多。「**不動産特化**」「**建設業界特化**」とワードを組み合わせることで独自性が生まれ、新事業として成立。**「AI社員」を商標申請中**（早ければ 2027-01 取得予定・未確定） |

#### 2.3.3 1to1 の質的転換

- 「こういう人を紹介してください」という **外部依存型** から、「**一緒に何が作れるか**」を考える **内部創造型** へシフトすると、1to1 からの展開スピードが上がる。
- 相手の事業を聞く際は「**何が伸びていますか？ 何が伸びていませんか？**」と具体的に質問し、不足・欠点を把握して提案につなげる。
- 他メンバーの商材を「**自分の商品と同レベルで説明できる**」状態にしておくと、顧客からの信頼が高まりリファーラルの質が上がる。

### 2.4 太田セッション: ファインバブル「ピュアバブル」深掘り

#### 2.4.1 商材ポジションと市場機会

| 論点 | 内容 |
|------|------|
| **位置づけ** | 白物家電（洗濯機・冷蔵庫）と同様の「**新しい生活インフラ**」として普及段階にある商材。大企業も今まさに取り組み始めており、**大企業と同じスタートラインで先行者利益が取れる**稀なタイミング |
| **市場ギャップ** | 大手ハウスメーカーの営業マンですら「まあいいんじゃないですか」程度の説明しかできない。**商品と市場の知識ギャップが大きいほどビジネスチャンス**（AI と同じ構造） |
| **普及が遅い理由** | 商品名の知名度不足（「ミラブル」「ReFa」級の名前なら 100 倍売れるとの見解）と、**工業用途からのスタート**でエンドユーザーへの浸透が遅れていること |

#### 2.4.2 商品ラインナップと価格

| 項目 | 内容 |
|------|------|
| **ピュアバブル（全館タイプ）** | 水道管の根元に設置し家中の水をファインバブル化。**顧客向け価格 236,000 円 ＋ 工事費（目安 50,000〜70,000 円）= 合計約 300,000 円** |
| **ピュアバブルスポット** | 賃貸・テナント・マンション向け。洗濯機・シャワー・シャンプー台など **特定箇所のみ**に設置可能 |
| **不具合実績** | 累計 **約 2,000 本**販売で不具合 **ゼロ**。機構がシンプルで機械的可動部がないため |
| **耐久性** | 半永久使用可能（実験データは **20〜30 年分**）。それを超えた場合はリフォームタイミングでの交換が必要になる可能性あり |

#### 2.4.3 取扱店（代理店）のメリット

| 項目 | 内容 |
|------|------|
| **参入条件** | **加盟料不要・在庫リスクなし・1 本から仕入れ可能**（業界唯一） |
| **収益シミュレーション** | 代理店仕入れ **160,000 円（税抜）** → 顧客販売 **236,000 円 ＋ 工事費**。**本体差益だけで 76,000 円／本**。工事費の利益設定は取扱店が自由に決定 |
| **クレーム・問い合わせ** | すべて **太田側の公式 LINE** で受付。取扱店は「**販売と取り付けだけに集中**」できる |
| **研修・サポート** | 営業研修・オリエンテーションあり。太田の過去の訪問販売経験から、研修なし・フォローなしの代理店モデルの問題を熟知しているため **手厚いサポート**を用意 |

#### 2.4.4 紹介・営業のトリガーと投げかけ方

| 項目 | 内容 |
|------|------|
| **反応しやすい業者** | **新しい商材を増やしたい**業者／**収支が良くない**（仕入れに大きな資金をかけられない）業者。1 本から仕入れられるため資金力が乏しくても始めやすい |
| **紹介トリガーワード** | 「**収支改善**」「**新しい収益の柱**」「**在庫リスクなし**」「**大企業と同じ商材を今から扱える**」 |
| **取り付け不可でも可** | 紹介者自身が取り付けできなくても、「**動いてくれる業者がある**」状況なら取扱店として参加可能 |

#### 2.4.5 Q&A（太田セッション）

| 質問者 | 質問 | 回答（太田） |
|--------|------|--------------|
| 渡邊 真大 | 単価が安い商材で工務店は食いつくか？ | 建材は通常ロット仕入れで支払総額が膨大になるが、ピュアバブルは **1 本単位**で仕入れられ支払総額が圧倒的に安く、**キャッシュフロー負担が小さい**ことが差別化ポイント |
| 小森 保人 | 集合住宅・マンションへの対応は？ | 分譲住宅は水道メーター横に設置スペースがあれば **全館対応可**。賃貸は **4〜6 戸程度**なら根元から対応可能、それ以上は **スポットタイプ**を推奨。オーナー承認があれば賃貸全体への導入も可 |
