## 5. エデュケーションコーナー（竹内駿太）

**テーマ:** テニスのコートサーフェス戦略をビジネスコミュニケーションに応用

| 観点 | 内容 |
|------|------|
| **比喩** | 四大大会ではコート（芝・クレー・ハード）によりボールの弾み・スピードが異なる。トッププロはスタイルを押し通さず、コートに合わせて戦い方を適応させる |
| **ハードコート型** | スピード重視。結論を端的に、素早い判断を好む。経緯をだらだら話すと飽きられる |
| **クレーコート型** | プロセス・共感重視。じっくり信頼関係を構築。結論を急ぎすぎると「売り込まれる」と警戒される |
| **最大の失敗（アンフォースドエラー）** | 相手がクレー型なのに自分のハードコート型を押し付けること |
| **リファーラル活用** | パワーチームへ見込み客を紹介する際、「この社長はじっくり聞いてほしいクレーコート型」等の情報を添えると、受け手が事前準備でき、商談でのコミュニケーションエラーが減り成約率が上がる |
| **拡大目標** | 現在51名→**75名**体制。75名時のリファーラルパスコースは **2,775通り**（約2.2倍）。多様なコートに対応できるプロ集団になれば成果も2.2倍以上に |
| **今週のワーク** | 予定している1to1や商談の前に、相手がハード／クレーのどちらかを一度想像してから臨む |
