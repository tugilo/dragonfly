## 4. エデュケーションコーナー（横山尚武）

**テーマ:** BNI とはどんな場所？

| 観点 | 内容 |
|------|------|
| **核心** | BNI は狩猟型ではなく **農耕型** の紹介文化。「刈るものではなく育てるもの」 |
| **土を耕す** | まだ話していないメンバーやビジターと積極的に 1to1 を組むことが、土を耕す作業になる |
| **今週の行動** | 今週中に誰かとカレンダーに予定を入れる。**5分の Zoom でも可** |

### DC インフォメーション（茂木禄人）

| 観点 | 内容 |
|------|------|
| **成功者の共通点** | **コンフィデント・リスクテイカー** — 成功を強く信じ、自ら投資・挑戦する人 |
| **推奨行動** | トレーニング受講／未経験の相手との 1to1／過去の 1to1 相手との再接触 |
| **閉会の一言** | 「対面だったらその行動をするか？」の視点で VCP を意識し、細部にこだわることがチャプター活動の質を高める |
