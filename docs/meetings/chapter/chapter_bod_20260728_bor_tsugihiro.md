## BO① オープンネットワーキング（10:00〜10:25・**25分**）

**テーマ:** 自己紹介を交えて、ビジネスの交流で場を温める。  
**位置づけ:** 今日いちばん長い BO。売り込みタイムではなく、**相手を知り・覚えてもらう**時間。

### 進め方（25分の使い方）

| 分目安 | やること |
|--------|----------|
| 0–2分 | 全員の名前・カテゴリーを一周（短く） |
| 2–20分 | **2〜3人ずつ** 深掘り（1人あたり数分）。聞く7：話す3 |
| 20–25分 | 「今日つながれた人／あとで1to1したい人」を一言ずつ |

**自分の役割:** ファシリ気味に回すなら「次、◯◯さん聞かせてください」。自分が話すときは **30秒自己紹介 → 質問に戻す**。

### 自己紹介（30秒・入口だけ）

> AI業務改善の次廣です。静岡からオンラインです。  
> **売上は伸びているのに現場が追いついていない会社**の、仕事の流れづくりをしています。  
> 今日は売り込みより、皆さんが **いま何を伸ばそうとしているか** を聞かせてください。

### 会話で使う質問（ローテ用・3つまで）

1. 「いま一番、時間を食っている業務は何ですか？」
2. 「理想のお客様って、どんな人・会社ですか？」
3. 「今日の BOD に来た理由、一言で言うと？」

### 自分が話す中身（聞かれたとき・1〜2分）

> Excelが限界、同じ入力を何度も、あの人しか分からない —— このどれかが出ている会社に入って、**人を増やす前に仕組みで伸ばす**。  
> 「AIの人」より、**何を・なぜ作るかを一緒に決める構想パートナー**だと思ってもらえると近いです。  
> 直近は増本さんの害虫ブロック本部で、取扱店が増えて本部が重くなったところを、1回入力で回る土台に変えた、というのが型です。

### 25分で持ち帰るもの（自分用チェック）

- [ ] 同室の **ビジター名＋カテゴリー** をメモ（あとでアテンド／紹介者へ）
- [ ] 「欲しい紹介」が聞こえた人を **1人以上** 特定
- [ ] 自分の招待（石原・山野・吉田・戸塚）が同室なら、**安心感の一言**（「今日は体験重視で大丈夫」）
- [ ] 売り込み完結させない。**本編②③④で深める種**だけ拾う

### 補足

- 初対面には短く・具体例1つ。既知（石原さん等）には近況と「今日の見どころ」だけでよい。
- 沈黙が怖いときは質問1へ戻す。自分の話を長くしない。

## BO② ビジネスの現状と目標（10:43〜10:55）

**テーマ:** 「今、私のビジネスは◯◯です」「私の目標は◯◯を達成したい」

### 話すこと（1つに絞る）

> **今のビジネスと結果:** tugilo は、経営者の時間を生み出す構想パートナーです。Excel・手作業・二重入力の限界を、**1回入力で回る流れ**に変えています。  
> **いま見せられる結果**として、BNI に入ってリズムが整い、**今期は売上倍が見えています。** 紹介と1to1が、仕事の量と質に直結し始めている、というのが現状です。  
>
> **その上で、こうなっていたい。**  
> **1年後** — 売上倍を「たまたま」で終わらせず、**紹介経由の伴走相談が月1件ペース**で回り、「時間を生み出すSE」で名前が出る状態。数字が再現できる流れになっていること。  
> **3年後** — 一人受注の延長ではなく、FC・複数拠点など **一人では取れない規模**を、開発・士業・現場の仲間と **パワーチームで受注・完遂**し、チームとしての売上・事例が残っていること。  
> **5年後** — 自分が全部手がけるのではなく、同じ型を回せる **パートナー・後輩**が現場を支え、tugilo が **構想パートナー**として選ばれ続けていること。「人を増やす前に構造を変える」が、紹介される側の当たり前になっていること。  
> 今日の BOD は、その **1年後の種**を、角度の高いビジターと一緒につくる日です。

### 言い換え（さらに短い版）

> **結果:** 今期は **売上倍が見えている**。  
> **その先:** **1年＝倍を再現できる紹介の流れ（伴走 月1）** → **3年＝仲間と大規模を完遂** → **5年＝型が人に移る**。今日はその入口。

### 補足メモ（結果が見える言い方）

| 軸 | 見せる結果 |
|----|------------|
| **今（今期）** | **売上倍が見えている**（入会後のリズム・紹介・1to1の効果） |
| 現状の中身 | 構想パートナー。増本さん型の伴走。まだ「AIの人」で止まることがある |
| **1年後** | 倍を **再現** — 卵＋ガチョウ経由の伴走 **月1件**、名前で紹介が来る |
| **3年後** | パワーチームで **大規模案件を完遂**（FC・複数拠点）。チーム売上・事例が残る |
| **5年後** | **自分がボトルネックでない** — パートナー／後輩が同じ型で回し、構想パートナーとして選ばれ続ける |

## BO④ BNI成功の鍵について（11:43〜11:51）

**テーマ:** 出席・時間の確保・貢献 — 実際にできるものなのか？

### 話すこと（1つに絞る）— 時間＋トレーニングの学び

> 結論から言うと、**できます。ただし気合いではなく、時間の取り方と向き合い方を決めている**からです。  
>
> **時間の使い方。**  
> **火曜は必ずカレンダーにブロック**しています。朝のチームMTG（スリーバイス・8:00–8:45）から定例会まで、その日は BNI の日。クライアント作業を入れない。欠席は例外です。  
> **1to1（121）の時間も、すべて営業と捉えて活動しています。** 雑談枠ではなく、紹介の種を拾い、相手の欲しい紹介を聞き、自分の事業にもつながる時間。だから「空いたらやる」ではなく、**先に予定を入れる**。  
> 定例のウィークリー・BOR・ビジター招待・記録も同じです。**BNIに使う時間＝営業時間**。今期の売上倍が見えているのも、この取り方の結果だと思っています。  
>
> **もう一つ、トレーニングでの経験です。**  
> ベーシックやキースキルズを受けて感じたのは、**素直な人ほど成功している**、ということ。枠を取っても、「自分はもう分かっている」だと伸びない。教えられたことをそのまま試し、フィードバックを受け、直す。時間のブロックと、この素直さがセットだと、私は思っています。  
>
> 忙しい経営者ほど、「あとでやる」は無理です。**火曜をブロックできるか、121を営業として置けるか、そして素直に学べるか** —— それが成功の鍵だと思います。

### 補足（深掘り用）

| 枠 | 実態 | 捉え方 |
|----|------|--------|
| **火曜（終日ブロック）** | チームMTG 8:00–8:45 → 定例（本日は BOD） | **BNIの日。クライアント作業を入れない** |
| **121（週に数本）** | 先に予定を入れる | **すべて営業** |
| **トレーニング** | ベーシック・キースキルズ等を受け、定例・121に落とし込む | **素直に試し、直す**。分かったつもりにしない |
| **成功の型** | 枠を取る × 素直に学ぶ | **素直な人ほど成功している**（体感） |
| **貢献** | 紹介・ビジター・記録 | もらう前に出す＝営業の入口 |

### 聞き返す一言

「火曜をブロックできますか？ 教えられたことを、素直に試せそうですか？」

## BO⑤ オリエンテーション（12:00〜12:15）— **山野佑一郎さん担当**

**テーマ:** 入会・参加のオリエン  
**対象:** 山野 佑一郎さん（通信機器販売）

### オリエンで伝える芯（1つに絞る）

> 山野さんは個人事業主ではなく、**取引先GOODMANさんの営業**としてここにいる。BNIの使い方は「自分一人の集客」だけでなく、**会社の営業チャネルを、信頼ベースの紹介に置き換える**イメージが近い。  
> 今日感じてほしいのは、売り込みの場ではなく、**「誰の・どんな困りごとを聞ける場か」**。それが分かれば、火曜をブロックする価値があるかどうか判断できる。

### 山野さんの立場でBNIをどう活用するか（具体）

| 使い方 | 具体アクション |
|--------|----------------|
| **① 欲しい紹介を毎週言い続ける** | すでに口に出している型でよい。**新設・移設予定の方**／**通信まわりの問い合わせ先が多数あり困っている方**。ウィークリー25秒と121で同じ言葉を繰り返す。 |
| **② GOODMANの強みを「症状」で伝える** | 製品名より先に、「回線・端末・工事の窓口がバラバラで困っている会社」に刺さる一言。次廣と同じく、**ツールの話より困りごとの話**。 |
| **③ DragonFlyをGOODMANの紹介入口にする** | メンバーの顧客・知人で移設・拠点増・通信整理があるとき、**山野さん＝まず相談してよい通信の人**と覚えてもらう。121で「どんな会社なら紹介しやすいか」を相手に聞く。 |
| **④ 次廣（tugilo）と役割分担する** | 現場がExcel限界・仕組み化 → **次廣**。回線・端末・移設・窓口整理 → **山野／GOODMAN**。同じ経営者の話でも、困りごとで振り分けると双方の紹介が増える。 |
| **⑤ 121はすべて営業（会社の営業）** | 個人の趣味交流ではなく、**GOODMANのパイプライン作り**。火曜定例＋週数本の121を、会社の活動として上司・会社に説明できる形にする（許可・報告の線を先に決める）。 |
| **⑥ 出せる紹介も持つ** | 「業種・規模の異なる会社とつなげる」は山野さんの強み。GOODMANの既存顧客・商談先で、他メンバーの欲しい紹介に合う人を **月1でも返す**。もらうだけにしない。 |
| **⑦ カテゴリー・入会の実務** | 通信機器販売で入会する場合、**会社承認・費用負担・名刺表記（個人／会社）**をメンバーシップに確認。社員入会は「本人の時間」と「会社の許可」がセット。 |

> 山野さんは **GOODMANさんの営業**として来ている。BNIは、テレアポや飛び込みの代わりに、**信頼できる紹介で「移設・新設・通信の窓口が散らかっている会社」に出会う場**だと思ってほしい。  
> 使い方はシンプルで、  
> **毎週「新設・移設」「通信の問い合わせ先が多くて困っている方」と言う。**  
> **121で相手の欲しい紹介を聞き、GOODMANの顧客からも返す。**  
> **仕組み化の話が出たら次廣に振る。通信・移設の話が出たら山野さん。**  
> 火曜を会社の営業時間としてブロックできるか、素直にトレーニングを試せるか —— それが続くかどうかの分かれ目。  
> 今日の感想を、芳賀さんか私に一言ください。入会する／まだ決める、どちらでも前進です。
