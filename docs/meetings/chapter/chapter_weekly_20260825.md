### 増本重孝 — 虫が建物に近寄らない液体製造（株式会社ワイエスエス）

| 観点 | 内容 |
|------|------|
| **背景** | 極貧家庭出身。中学卒業後に社会へ。19歳で「社長になりたい」、21歳で個人事業、現会社を設立。商工会議所青年部会長経験をきっかけに社内「プロテクトラボ」を設立し害虫ブロックを開発 |
| **商品** | 昆虫が嫌がる液体を建物外部に噴霧し侵入を防止。蜂・クモの巣形成を阻止。効果は夏季3〜4ヶ月。虫は外から入るため侵入防止が根本策。競合のない商材 |
| **現場** | 食品工場・パッケージ工場・温泉旅館・キャンプ場・住宅・マンション・店舗。噴霧機で吹きかける施工。営業・女性でも対応可 |
| **安全性** | 人畜無害（醤油より安全）。日本中毒情報センターの致死量比較でも確認 |
| **募集** | 取扱店（施工店）を全国募集。塗装・リフォーム・外構業に向き、既存業務のついでに拡大可。初期費用 **55万円**・会費／ロイヤルティなし（通常の特別商材は契約時200〜300万円＋会費が多い） |
| **新製品** | 飲食店専用スプレーボトル開発中（**翌年3月**発売予定）。超強力・人畜無害・非引火の厨房向け |
| **ビジョン** | 「頑張るものが報われる世界へ」。一緒に稼いで納税し、国を豊かに |

### 芳賀崇利 — 求人採用の戦略設計（株式会社イマジン）

| 観点 | 内容 |
|------|------|
| **背景** | 埼玉・三郷出身。建築金物取り付け工として首都圏商業施設（TDL・六本木ヒルズ等）の施工管理。33歳で山形へ移住。2014年に地域情報サイト、**2016-09-01** 株式会社イマジン設立。全国4エリアで延べ **350社以上**の求人採用集客を支援 |
| **カテゴリー変更** | 本日より「**求人採用の戦略設計**」（旧: 地域情報サイト運営） |
| **課題** | 成功の3要素＝①知ってもらう ②信用・信頼 ③応募の一歩。SNS・HP・求人媒体をバラバラ発注すると目的・ターゲット・動線が一致しない |
| **解決** | 10年の知見 × AI の診断ツール「**マスト**」。業種・地域・現行施策を入れると、350社超の DB から効果的な一手を設計・レポート化。認知→信用→行動を一つの流れに |
| **事例** | 越谷市の建設会社。Indeed 有料掲載1年（約80万円）で採用ゼロ → マスト診断で「越谷市内5万部ポスティング」＋求人ページ改修 → **7名応募・3名採用** |
| **価値** | 採用支援事業者は自社サービスに AI 診断を足せ、**成約率**・客単価の向上が期待できる（要約「制約率」は成約率と校正） |
| **今後** | ベータから最新版リリース間近。BNI で全国展開 |
| **求める RF** | 採用支援をしている事業者で、いまの採用サービスの成約率を上げたい方 |
