|------|------|
| **核心** | 世界で勝つチームは、前走者が立ち止まる前に受走者が助走を開始し、トップスピードで走りながらバトンを渡す |

| 項目 | 内容 |
|------|------|
| **背景** | 20代は月給20万円のサラリーマン。起業後3ヶ月間 **無給**（要約「無賃銀」）を経験。BNI入会後、初月で70万円の売上。会社設立1年目の売上1,500万円、今年は2,000万円が目標 |
| **BNIとの縁** | 今年2月に結婚した夫との出会いも BNI メンバーからの紹介 |
| **サービス** | 建設会社を中心に業務効率化・事務作業の仕組みづくり。Excel 二重入力・紙や LINE への情報散在・属人化業務を解消 |
| **具体例** | 現場情報を一度入力 → Google カレンダーへ自動反映／見積書・請求書をボタン一つで自動作成／LINE に写真や日報を送るだけで Google ドライブ保存・スプレッドシート集計・報告書反映まで自動化 |

| **導入事例** | 従業員約10名の足場会社で、月約100時間かかっていた業務を仕組み化し **月80時間削減**。月給25万円の事務員換算で年間約150万円のコスト削減。導入費用約70万円で約6ヶ月で回収可能 |
| **料金** | **98,000円〜** の買い切り（固定のサブスク必須ではない）。導入後6ヶ月サポート付き。継続希望者向けサブスクプランあり |
| **金のガチョウ** | 建設業・農業の会社と仕事をしている財務コンサル・税理士・機器保険・採用支援の方 |
| **金の卵** | 従業員10名以下の建設会社で、今のやり方を大きく変えずに事務作業を楽にしたい社長 |
