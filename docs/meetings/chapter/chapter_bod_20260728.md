## 4. リファーラルマーケティングの解説

### 4つのマーケティング手法

1. 広告宣伝（Web広告、SNS 等）
2. PR（パブリックリレーションズ）
3. コールドコーリング（直接営業）
4. **リファーラルマーケティング（紹介）** — 本日のメインテーマ

### 現状と課題

| 項目 | 内容 |
|------|------|
| **認識 vs 実践** | **98%** の事業者がリファーラルを「重要」と考えている一方、戦略として実践しているのはわずか **3%** |
| **ギャップ** | 「紹介でもらえるのはありがたい」と感じつつも、年度事業計画に数値として落とし込めていない経営者が多い |
| **BNIの位置づけ** | リファーラルを **事業戦略として取り入れるためのプラットフォーム** |

## 6. ビジネスステージ別の課題と解決策（山崎勇一）

| ステージ | 課題 | BNIによる解決アプローチ |
|----------|------|-------------------------|
| **1** | キャッシュフロー不安定・売上不足 | リファーラルマーケティング導入で売上拡大 |
| **2** | 時間・人手不足 | 仕組み化の手本から学び、有効活用できる時間を生み出す |
| **3** | ビジョン浸透不足・右腕不在・社員のモチベーション低下 | リーダーシップを学び実践、影響力の輪を広げる |
| **4** | 新規事業機会の不足・事業のスケールアップ | 世界規模のネットワーク活用（インド・ヨーロッパ・アメリカなど） |

### チームを活用したクライアントアプローチの例

「家を買いたい女性」を例に、ファイナンシャルアドバイザー・不動産・司法書士・住宅ローン仲介などが個別にアプローチするのではなく、**一つのチームとして連携**することで効率的かつ包括的なサポートが可能になる。同じクライアント層を複数業種で探しているなら、**チームで探す方が効率的**。

## 9. BNI活用のベネフィット（5+1）

1. **大きなマーケティングチーム** — DragonFly は全国トップクラスの50名以上のチャプター  
2. **競合のいないビジネス環境** — 同一業種・業態はチャプター内に1名のみ  
3. **継続的な新規顧客の紹介** — リファーラルによる新規顧客獲得が継続  
4. **国内外に広がる人脈** — グローバルネットワーク（例: 11月モナコ、昨年4月沖縄で約3,000名）  
5. **長く続く有意義な信頼関係** — 生涯付き合い続けられる仲間  
6. **プラスワン（学びの場）** — 上記を効率的に発揮するためのトレーニング・学習環境

## 10. 入会条件・コスト・申し込み手順

### 3つの必須要件

1. **出席** — 火曜午前の定例会にほぼ毎週参加（年間約50回）  
2. **時間の確保** — リファーラルマーケティングへの投資時間として週約 **7時間**（1日1時間程度）  
3. **貢献の姿勢** — 相手のビジネスのために何ができるかを考えて行動する  

### 費用内訳（当日案内・税込）

| 項目 | 金額 |
|------|------|
| 登録費（初回のみ） | **50,000円** |
| プログラム利用料（1年） | **190,000円** |
| チャプター月会費（12ヶ月分） | **60,000円** |
| **合計（税込）** | **324,000円**（月額約27,000円） |

- 「社員を1名採用する1ヶ月分のコストと変わらない」と位置づけ。  
- 申込後の振込案内は **264,000円**（登録費＋プログラム利用料＋税の案内。月会費の扱いは申込時案内に従う）。公式申込画面を正とする。

### 申し込みの流れ

1. メンバーシップ申し込み（オンライン入力）  
2. 費用の振り込み（**264,000円**）  
3. 加入審査（DragonFly メンバーシップ委員会）  
4. 承認後: 最短翌週から定例会参加可能  

カテゴリー重複等で承認されない場合、または審査前に辞退した場合は **全額返金**。
