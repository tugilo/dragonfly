## 4つは別物

会話では「動画」が一つに見える。仕事は4段ある。

| 段 | 何をするか | いま（10期） | タスク |
|----|------------|--------------|--------|
| 録る | Zoom で定例会を録る | 手作業。開始忘れが論点。過去に28時間録画 | WM-06 |
| 切る | MP／Edu／ウィークリー／SS を切り出して NextCloud へ | Pipeline が自動。毎週動いている | WM-14 |
| 整える | 尺を整える、見栄えを付ける、編集する | 正本に「毎週手で編集している」記録は無い。工藤さん会は「保存・編集」を一括で廃止方向 | 未分離 |
| 出す | Facebook グループへ載せる | 手作業。自動化の例外 | WM-15 |

梅澤さんの「編集せず録画だけ」は、**録るを残し、切る／整えるを薄くする案**。採用ではない。  
工藤さん会の「毎週の動画保存・編集を廃止」は、**切る＋整える＋毎週出す**を減らす方向。Zoom の全録画は残る前提。

## 観測できている効果（と、観測できていないこと）

### 観測できている

| 効果 | 向き | 出典 |
|------|------|------|
| 誰が切るかが倉持さんに寄る。Pipeline が止まったら直せる人が少ない | 負荷・属人 | 棚卸し WM-14／WM-27。LT は「誰でもできる状態に戻してほしい」 |
| Facebook 投稿だけ毎週手作業が残る | 工数 | WM-15 |
| 増本さん「誰も見ていない」 | 視聴の感触。ログではない | [工藤さん会](webmaster_kudo_yuji_20260821.md) |
| Zoom に全録画があるので、必要な回だけ後から切れる | 録るだけで後追いできる | 同上 |
| 倉持さんの動画保存・自動化は善意から始まり、複雑化・ミス・属人化を招いた、で4者一致 | 副作用 | 同上 |
| NextCloud 約140GB／500GB。不要な過去動画は捨てて軽くする、が方向 | 容量 | 工藤さん会＋[倉持棚卸し](webmaster_handover_20260822.md) |
| 切り忘れで28時間録画になったことがある | 録る側の失敗 | WM-06 |
| 実視聴は不明 | 効果の欠測 | WM-14 メモ |

### 正本に無い（測っていない）

- 切り出し動画の再生数、完走率、何人が何回見たか
- 編集（整える）に何分かかるか。WM-14／15 の所要分は空欄
- メインプレ再聴アンケートの申込数
- Facebook 投稿を見て紹介や1to1が動いたか
- 欠席者が全録画を開いているか
- 11期で Pipeline を誰が持つか。止まっても定例会は回るか（回る。切る／出すが止まる）

視聴ログが無いので、「効果がある／無い」はまだ言えない。増本さんの一言は方向の場の感触。

## 段ごとの、目的と効果

運営思想 §10 の問いに、いま答えられる範囲だけ。

### 録る（WM-06）

| 問い | いま言えること |
|------|----------------|
| 何のため | 切り出しとアーカイブの前提。後から必要な回を取り出せる |
| 何が変わるか | 録らないと、切るも出すも後追いもできない |
| KPI | 入会率・更新率への直線は正本に無い。止めない定例会の記録側 |
| 定量 | 開始できたか、切れ忘れて異常尺になっていないか |
| 工数 | 所要分は空欄。開始忘れのチェックが本体 |
| 12期へ | Zoom 操作はチームで持てる。特殊ツールではない |
| 属人 | 低い（手作業）。忘れると失敗する |

録ることをやめる案は、正本に無い。

### 切る（WM-14）

| 問い | いま言えること |
|------|----------------|
| 何のため | あとから見返す。2時間の全録画から MP 等だけ渡す |
| 何が変わるか | 探す時間が短くなる。毎週の置き場と保守が増える |
| KPI | 正本に無い |
| 定量 | 実視聴は不明 |
| 工数 | 自動のあいだは週次の手は少ない。止まったときの保守は高い（WM-27） |
| 12期へ | 倉持さん以外は難しい、が棚卸しの評価 |
| 属人 | 高い |
| やめる・減らす | 工藤案は縮小〜廃止。残すなら半年に1〜2本。稼働中なので 8/22 はやめていない |

切る効果は「渡しやすさ」。視聴されているかは未測。  
切らなくても、Zoom 全録画があれば後から切れる（工藤さん会）。

### 整える（編集）

| 問い | いま言えること |
|------|----------------|
| 何のため | 正本に「毎週、見栄えのために編集している」目的は無い。工藤さん会は保存と編集を一括で語っている |
| 何が変わるか | 冒頭・尻・死んだ時間を除くと見やすい、は一般論。DragonFly の視聴差は未測 |
| KPI | 正本に無い |
| 定量 | 所要分も視聴差も無い |
| 工数 | 手で整えるなら技能と時間が要る。Pipeline の「切り出し」と「編集」は混ぜない |
| 12期へ | 整える人が固定されると、また一人に寄る |
| 属人 | 手編集は高い |

梅澤さん案（編集せず録画だけ）は、整える工数をゼロにする代わりに、探す手間と見栄えを受け取る。  
効果の比較データは無い。

### 出す（WM-15）

| 問い | いま言えること |
|------|----------------|
| 何のため | メンバーへの共有 |
| 何が変わるか | グループに載る。見て紹介につながる、は未測 |
| 工数 | 毎週手作業。所要分は空欄 |
| 属人 | 中。倉持のまま |

## いまある代替（編集の代わりになりうるもの）

代替は「編集しない決定」ではない。すでに別の道がある、という事実。

| 代替 | 何を代替しうるか | 出典 |
|------|------------------|------|
| Zoom の全録画 | 毎週切る／整える。必要な回だけ後から切る | 工藤さん会 |
| メインプレのアンケート→申込→深く聞く | 「もう一度聞きたい」の深い側。動画を配るより人が介在する | 梅澤さん。フォームは未確認 |
| ロールモデルの 1toMany を録って新入会へ | 毎週の MP 切り出しとは別。新入会が事例を見る | LTST 9/10 |
| Webマス自身が当日聞く | 紹介の機会。動画の再視聴ではない | 11期のペアの狙い |

---

## 11期の物差し（切るとき）

便利・自動、だけでは残さない（運営思想 §10／目標資料）。

残す／減らす／やめるを切るときは、最低限これを埋める。

1. どの段か（録る／切る／整える／出す）
2. 誰のためか（欠席者／再聴／新入会／FB／WM の管理）
3. 視聴か申込かの数字（無ければ「未測」と書く）
4. 所要分（切る・出す・止まって直す）
5. 倉持さん以外が回せるか
6. やめるなら、Zoom 全録画とアンケート再聴のどちらが受け皿か
