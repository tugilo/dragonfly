## 来期の指針と目標（今夜の地図）

10月スタート。中身は、引き継ぎと LTST で既に出ているものだけ。今夜は新規施策を足さない。

### 章の向き（知る。宿題にしない）

| 層 | 言葉 |
|----|------|
| スローガン | 成果にこだわり、誇れるチャプターへ |
| メンバーへの一本 | **1to1 を徹底する** |
| KPI（管理数字） | 入会率 4.2%→**8%**、更新率 60%→**70%**。メンバーに配らない |
| ST指針 WEB | 「定例会に一つのミスも無いように人員も含め準備する。」ミスゼロは理想。手段はリカバリと6人 |
| ST指針 締切 | メンバーへの締切は **月曜正午** で統一 |
| 運営思想 §9 | 引き継ぎ・棚卸しが終わるまで、既存運用を推測して改善対象にしない。最優先は定例会の確実な遂行 |

Webマスの仕事は、会が止まらないことで 1to1 と入会の土台になる、まで。フォーラム80%・受講率60% などは触らない。

### チームの目標

[目標と約束](webmaster_term11_goals_20260827.md) とシート Webマス行を同じ3つにする。

1. **毎週の定例会を止めない。** ミスが起きたときの対応力。
2. **オンラインでも、人が伝わる。** メンバーが安心して進められる。
3. **誰もができる Webマス。** 11期で終わらせず、次の期へ渡す。

軸: **次廣がいるから回る、じゃなくて、チームがいるから回る。**  
一文: 皆が定例会に集中できる状態を作り、そこから自然と 1to1 とビジターの入会につながる。  
裏（チーム内）: ゲストに「DragonFly やべえ」と思わせる。表のスローガンには出さない。

### すでに上がっているやり方（9/10。9/17 でフィックス）

| 項目 | 方向 |
|------|------|
| 回し方 | 6人。**係を固定しない。ローテーション。** 休んでも回る |
| スライド送り | 朝礼含むパワポ **4つ**。各共有は **2人1組**。メインが共有＋送り、サブも同じページ。切れたらすぐ切替 |
| なぜペアか | **①切れても止まらない**（リカバリ）。**②Webマス自身がウィークリー／メインプレを聞き、リファーラルの機会を失わない** |
| 締切 | 朝礼スライドは **月曜 12:00**。リハを「初めて直す場」にしない（ユウジさんの型） |
| 月曜 MTG | 8時〜11時まで伸びることがある。確認事項を精査し、チーム内で完結する項目は会の外へ |
| PC | 運営用ノート 37,800円（Office付き・16GB）を船津へ申請し、LTST 決裁。既存端末2台は11期も使う見込み |
| 当日の判断 | 時間調整（BOR短縮など）はプレジ／バイスが切る型を守りたい。WM が全部引き受けない |

棚卸しは出た。残す／やめるは、操作を覚えてから。今夜は切らない。

## ペアの狙い（2人1組）

LTST 9/10。週のペア割は未決。型だけ共有する。

1. **切れても止まらない。** メインが共有＋送り、サブも同じページ。切れたらすぐ切替。

ローテーションで全員がメインもサブもやる。片方しかできない状態は作らない。
