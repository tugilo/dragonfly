## 使い方

1. 作業は [Sheets](https://docs.google.com/spreadsheets/d/1TWadVczKpOXQTy76-3cij-kYOTfFi2eGl7bHyoKrsh4/edit) で行う。正本は CSV。
2. 1行目でフィルタを付け、「個人・良かれ」だけ見る。
3. 倉持さんと「所要分」「判断」「今もやっているか」だけ埋める。
4. 判断は次から選ぶ: **残す／改善／仕組み化／自動化／分担／やめる**。空欄は **未決**。
5. 習得が進んだら「習得」列だけ更新する。

---

## 列の意味

| 列 | 意味 |
|----|------|
| 区分 | 毎週／当日／会後／不定期／基盤／移行／実験／停止中／協議／**個人・良かれ** |
| 所要分 | 1回あたり何分か。未記入＝まだ聞いていない |
| 属人度 | 倉持さん以外が止まったとき困るか |
| 手で同じことができるか | ツールが死んでも定例会が回るか |
| 習得 | 倉持のまま／次廣習得中／次廣担当／分担先へ／未配備／停止中／協議中 |
| 判断 | 11期 §9。便利だから残さない。操作を覚えてから LT・ST と切る |

## 見るときの切り口

- **倉持のまま** … まだ次廣が持っていない。9月末までの本体。
- **属人度が高＋自動** … 止まったとき直せる人が論点（Pipeline、BORアプリ、Canva）。
- **所要分が空** … 次の倉持さんとの作業で埋める。
- **判断が未決** … 正しい。今夜の棚卸しでは切っていない。
- **個人・良かれ** … 役職の必須作業ではなく、倉持さんが便宜・品質のために足したもの。フィルタで切って見る。
