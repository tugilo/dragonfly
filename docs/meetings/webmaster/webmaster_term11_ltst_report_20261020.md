**【相談】**

4. **2回目 BOR 前の「各部屋の感想」の人数を、あらかじめ決めておけないか**
   2回目の BOR は、ビジターホストが各部屋に感想を聞いている間に作っています。
   ビジターの数が回によって違うので、ギリギリ間に合う時と、少し待っていただく時があります。
   「2回目のルームできてますか？」「もう少し待ってください」をなくしたいので、
   感想を聞く人数を **ビジターの数で事前に決めて** いただけると、Webマス側で確実に間に合わせられます。
   例: ビジター **10人以下なら各部屋 1人**、**11人以上なら各部屋 2人**。
   ビジターが多い回は各部屋から 2人紹介できる形にもなるので、ビジターにとっても、定例会の進行にとっても良いのではと思っています。
   → 人数の線引きは案です。ビジターホスト側の進行に支障がなければ、ご検討ください。
