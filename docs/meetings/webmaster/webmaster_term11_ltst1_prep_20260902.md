## 4. 全体協議: Microsoft 365 1ライセンス（3分の2 が要る）

### 理由の骨（この順で言う。逆にしない）

```text
皆が定例会に集中できる状態を作る → 自然と 1to1 → ビジターの入会（ここが目的）
裏の目標: ゲストに「DragonFly の定例会、やべえ」と思わせる（誇り → 誘いたくなる → 入会率）
  → そのために、定例会をミスなく安定させたい
  → ミスはゼロにできない。起きたときのリカバリを徹底する
  → その型が「スライド送りは常に2人1組」（メイン＋同じページを送るバックアップ。切れたら即切替）
  → パワポは朝礼含め4本 = 4組。6名全員が共有担当に入れないと、毎週2人1組を組めない
  → 6名のうち1名だけ、デスクトップ版 PowerPoint が無い（ブラウザ版のみ）
  → 定例会スライドは BGM・効果音・アニメ入り。ブラウザ版は音と動きが欠け、Zoom もタブ共有になり本番で使えない
  → その1名が入れない週は、2人1組が崩れる
  → だから1ライセンス。チャプター資産として持ち、12期にも渡す
```

「PC が無いから買ってほしい」ではなく、**「リカバリの型を毎週守るために足りない最後の1枚」**として言う。名前は出さない。

### 口頭（約60秒・コピー用）

> Webマスの全体協議です。Microsoft 365 を1ライセンス、チャプターで購入させてください。
>
> Webマスが目指すのは、皆が定例会に集中できる状態を作ることです。そこから自然と 1to1 につながり、ビジターの入会につながる。そのために、定例会をミスなく安定させたい。ただ、ミスをゼロにはできません。だから、起きたときのリカバリを徹底します。
>
> その型が「スライド送りは常に2人1組」です。メインが共有してページを送り、バックアップも同じファイルを開いて同じページを送り続ける。メインが切れたら、その瞬間にバックアップが共有を引き継ぎます。
>
> 定例会のパワーポイントは朝礼を含めて4本あるので、4組が必要です。Webマスは6名。全員が共有担当に入れて、はじめて毎週2人1組を組めます。
>
> 事前アンケートで、6名のうち1名だけ、デスクトップ版の PowerPoint がありませんでした。ブラウザ版だけです。定例会のスライドは BGM・効果音・アニメーションが入っているので、ブラウザ版だと音と動きが欠け、Zoom の共有もタブ共有になって本番では使えません。その1名が入れない週は、2人1組が崩れます。
>
> なので、足りない最後の1枚として1ライセンスをお願いしたいです。個人名義ではなくチャプターの資産として持ち、担当が変わっても12期に渡せる形にします。金額は年額 21,300円です。

### 15秒版（時間が無いとき）

> 定例会をミスなく回すために、スライド送りは常に2人1組でバックアップを置きます。そのために Webマス6名全員が共有に入れる必要がありますが、1名だけデスクトップ版 PowerPoint が無い。ブラウザ版は音と動きが欠けて本番で使えないので、1ライセンスをチャプター資産として購入させてください。年額 21,300円です。
