## パワーチーム構築に関する議論

### 横山さんの提起

| 観点 | 内容 |
|------|------|
| **現状の傾向** | BNIのパワーチームは「業種が近い者同士」で組む傾向があり、それだけでは展開が限られる可能性 |
| **後工程の視点** | 自分の事業が誰かの事業の「**後工程**」（要約「術後」）になるパターンもある |
| **異業種マッチング** | 製造業×Web系などでも組める可能性。各メンバーの業種を洗い出してマッチングする発想が有効では、と提案 |

### 小中さんの補足（アライアンス勉強会の知見）

| 観点 | 内容 |
|------|------|
| **課題のバリューチェーン** | 自分が解決できる課題の前後には連鎖した課題が必ず存在する |
| **例（採用）** | 上流: 「売上がない」→「起業方法がわからない」／下流: 採用後の「定着率」 |
| **組み方の軸** | ①**業種軸**（横山さんの提起）②**課題軸** — 一連のバリューチェーン上で近い課題を持つ者同士が組むとシナジーが高い |
| **スリーバイスの現状** | 現在のチームは課題軸に近い組み方をしているチームではないか、と分析 |

## 121（ワントゥーワン）活用の重要性

| 観点 | 内容 |
|------|------|
| **比喩** | 121は BNI における **バッターボックス**。121をやっていないことはバッターボックスに立っていないのと同義で、ホームランもヒットも生まれない |
| **イチロー比喩** | 鈴木一朗でさえ打率3割＝7割は外す。だからこそ継続的実施が重要 |
| **考えてほしい問い** | ①どういう121が自分にとってベストか？②良い121を提供してもらうために、自分はどうギバーとして行動すべきか？ |
