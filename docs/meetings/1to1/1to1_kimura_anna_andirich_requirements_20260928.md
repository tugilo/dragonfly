## 1. 何のためのシステムか

職人からの日報連絡をアプリに載せ、日報作成と給与計算を自動化する。社員・契約社員・外注の情報を1か所に置き、現場入場、書類、施工写真の扱いを楽にする。

いまは LINE の日報を Excel に貼り、写真と資料は LINE からもらって共有フォルダに入れている。現場の LINE トークは、このシステムに置き換えて廃止する。

見積は **みつもろう** を今後も使う。給与計算ソフトは使っていない。締めは **25日締め、5日払い**。イレギュラーが多い。

## 4. 幹に載せる機能

第4回は機能番号まで「これが必須」とは切っていない。依頼資料が必要な機能とした 1〜4 と、予定表（6）を幹の候補とする。5（写真のAI）と「その他やりたいこと」はオプション枠。

### 4.1 職人・社員の登録

区分は社員、契約社員、外注（個人・グループ）。

社員・契約社員: 個人情報、契約書、持込車両の確認、電子署名、資格証。

外注: 所属名、個人名、個人情報、日当単価、必要書類（例: 一人親方労災）、契約書、持込車両の確認、電子署名、資格証。

必要書類が揃うまで登録できない。登録が完了した人だけ現場に入れる。

誰が登録し、申請と承認を置くかは第4回で未決。

### 4.2 工事の登録と管理

会社で管理者登録した人だけが見られる。

項目: 工事名、短縮表記、元請、工期、金額（税抜）、見積書、注文書、材料購入先、下請業者、請求情報、締め日、現場資料（図面・仕様書）、請求状況、現場状況（請求済み、完了、次回検査など）。

工事が決まったら随時追加する。日報では、登録済みの工事から現場を選ぶ。

添付は、PDFのドラッグ＆ドロップ、ファイル選択、写真の撮影。

詳細を足して、あとからいつでも直せるようにする: 施主名、住所、仕様（色）、フリー項目。残日数などの項目追加も資料にある。どの欄に足すかは、PDFの矢印先がテキスト化できておらず要確認。

元請のマスタは「その他やりたいこと」側。

### 4.3 日報と給与

日報の項目（画面案）:

| 項目 | 入力 |
|------|------|
| 日付 | 初期値は今日 |
| 現場 | 現場名を選ぶ。なければ「その他」で自由入力 |
| 時間 | 初期値 8:00–17:00 |
| 休憩 | 初期値 12:00–13:00 |
| 氏名 | ログインしている作業員本人 |
| 自由入力 | 画面に2枠ある。項目名は資料上で未記載 |
| 宿泊 | ○か× |
| 現場状況 | 次回作業あり／検査／完了 |
| 作業内容 | 自由入力 |
| 次回作業内容 | 自由入力。予定表の作業へつながる |
| 日報連絡 | あり |

入力者は **作業員全員**（2026-09-28 11:25 JST 確定）。社員・契約社員・外注を含め、作業した本人が自分の日報を入れる。時間、本日の作業内容、次回の作業内容の代理記入はしない。現状の LINE では親方が全体グループにまとめて入れているが、その運用は置き換える。個人の作業内容をどこまで細かく管理するかは、まだ切っていない。

給与:

- 日報が給与へ自動で反映される。
- 社員・契約社員は **時間**。外注は **人工**。
- 画面にある集計: 時間外、深夜、深夜残業、出張、金額、休憩、完了。
- 期間検索。日付・所属・名前・現場名で絞る。所属と単価は利用者登録から出す。
- 給与はパスワードをかけ、特定の人だけが見られる。
- 25日締め、5日払い。イレギュラーが多いので、定型の労働時間計算だけでは足りない前提で見る。

### 4.4 現場の共有（写真・トーク）

現場ごとのチャットルーム。LINEに近い操作。写真と資料を送れる。写真はアルバムで残す。既読・未読がある。職人は過去のメッセージも見られる。現場の LINE は廃止する。

### 4.5 予定表

動き:

- 日報の「次回作業内容」から、作業内容を自動で作る。
- 登録済みの工事名（短縮表記）から、現場名を出す。
- 現場ごとの稼働人数、1日の総稼働人数、現場数を自動集計する。
- 前日の予定を引き継ぎ、必要なところだけ入れ替える。
- 資料の画面は、職人名を現場へドラッグして動かし、車両・出張・下請・完了をボタンで選ぶ。
- 現場名をクリックすると、その現場の情報へ飛ぶ。

第4回の合意は、この中身を Excel の格子のまま見せないこと。職人が **今日・今週・今月** で分かる画面にする。格子を残すか、期間の切り替えにするかは、見積の画面案で示す。

職人が予定表を見られることは、職人向け範囲に含まれている。
