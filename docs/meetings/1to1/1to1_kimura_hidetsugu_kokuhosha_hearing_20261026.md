   - → **回答:** 未聴取。ポータル PDF は「特定出版社」1 系統、Excel はその他出版社。社数・比率は次回
4. PDF を見て VB 画面に入れるとき、**どの項目を、どこを見て入れるか**（得意先・書名・部数・判型・仕様・台割・見本日・配本日・希望日・備考）。迷う項目はどれか
   - → **回答:** 抽出項目はモックではなく **実業務の入力項目に合わせる**。現行 VB 受注入力画面（基本情報・詳細情報）のスクショは **13:33 受領**。新刊は全項目、重版は日付・部数のみ修正。対応表は [要件整理 §2〜3](1to1_kimura_hidetsugu_kokuhosha_requirements_20261026.md)

   - → **回答:** **新刊 5〜13 分/件、重版は大幅短縮**。PDF は毎朝 9 時にまとめて、Excel は随時（平日都度）。人数は未聴取（実務は鈴木さん・香川さん）

   - → **回答:** 主なリスクは **部数・ページ数・書名**。新刊時は全項目が対象。**別担当者のダブルチェック**で検出・修正

   - → **回答:** 現状は **PDF を紙に印刷し、製本日を手書き**してから入力・予定へ。→ 新システムでは印刷・手書きを廃止し **画面のカレンダーで製本日を入力**
