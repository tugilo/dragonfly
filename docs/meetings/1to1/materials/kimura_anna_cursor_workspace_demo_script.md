# 第3回121 ライブデモ台本（Cursor 実演）

**使い方:** Zoom で Cursor を画面共有する。スライドを読むのではなく、**チャットに指示を打って結果を見せる**。所要約 12 分。

## 前提

- 本番の顧客シート・実メール・実カレンダーは触らない
- メールは下書きまで。送信しない
- 予定は読むだけ。新規作成しない
- このフォルダの CSV は架空の「サンプル運送」

## 画面共有の開き方

1. Cursor で `tugilo-os.code-workspace` または dragonfly を開く
2. チャットを新規にする（この準備チャットを見せなくてよい）
3. 左に表、右にチャットが見えるようにする
4. 最初に言うこと: 「今から説明するのではなく、実際に Cursor に頼んでみます」

```

杏那さん向けに、次だけ日本語で短くまとめてください。
```
