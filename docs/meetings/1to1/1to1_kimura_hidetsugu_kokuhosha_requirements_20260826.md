## 0. 作るもの（2本）

Web は1つ。画面は2つ。VB は触らない。

```text
【1】注文PDF → 入力
  PDFを読む
    → WebUI が項目ごとに解析して、編集できる入力欄に抜き出す
    → 人が直す
    → 登録
    → Oracle に書く（VB 手入力と同じ状態）

【2】作業予定表
  WebUI で製本作業予定表を組む
    （いまの Excel印刷＋手書きを置き換える）
```

2は、1で Oracle に入った注文を読む（推定: いま Excel が ODBC で引いているのと同じ）。印刷後の差し込み・工数・入れ替え・追加注文も、この画面でやる。

印刷されたあとの運用:

1. **一度印刷する** — Excel 上のその時点を紙に出す
2. **あとから差し込みが入る** — 印刷後に注文が足される
3. **縦列は作業場所** — 板橋1F／2F／ふじみ野（各予備）

5. **空きを見て差し込む／入れ替える** — 「ここに入るか」「どれと入れ替えれば回るか」
6. **追加注文は手書き** — 印刷（＝Excel／Oracle）に無い案件を空欄・予備に書く

第3回の「逼迫した枠に新規を入れると後ろがずれる」は、この差し込みと入れ替え。

| 手書き | 差し込み、入れ替え、工数、追加注文、斜線、略称、取り消し | 印刷後の編集 |

手書きでやっていること（システムが置き換える作業）:

1. **差し込み** — 印刷後の新規を、工数を見ながら空きに入れる
2. **入れ替え** — 矢印で場所・日・順番を変える。後ろが連鎖してずれる前提
3. **工数** — ○囲みの時間（1.5H / 2.5H / 3H / 6H 等）。「どこに入るか」の判断材料
4. **手追加** — 印刷に載っていない追加注文を書く（部数・日付付き）
5. **塞ぎ** — 空セルの稲妻／斜線。続き、または使えない枠
6. **メモ** — 印刷所・得意先の略、見本のみ、残数、合計部数
7. **訂正** — 印刷文字にバツを付けて書き換える
