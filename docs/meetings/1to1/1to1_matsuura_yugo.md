### アプリの概要と機能

- **開発の経緯:** 2026年7〜8月の仕事の空白期間に AI を触り始め、ChatGPT から Claude Code に移ってアプリを開発・リリース。
- **対応環境:** iOS（iPhone）と Mac（Apple シリコン経由）。
- **主な機能:**
  - 編集モードを3択から選べる（「喋りベース」「映像の綺麗さベース」など）。
  - 書き出し時に、動画の内容からタイトル案5個とハッシュタグを自動生成。
  - チーム共有。社内で動画を共有してコメントを残せる。タイムスタンプを指定した修正依頼もできる。
- **料金:** 月額1万・2万・3万円のサブスクリプション。どのプランも最低15本以上は作れる上限設定。
- **決済:** Stripe 経由のクレジットカード決済。カード情報はアプリ側に保存しない。
- **作った理由:** 企業が動画クリエイターに月4〜5本・10〜15万円で発注しても費用対効果が合わない、という課題を解くため。SNS のアルゴリズムでは投稿の頻度と本数が効くことも後押しになった。

- **コンテスト構想:** アプリで作る動画コンテストを開き、知人の YouTuber を審査員に招く案。X のフォロワーによる自然な拡散を狙う。
