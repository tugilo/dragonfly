### 4. 【必須】同時アクセスとは何か（よくある誤解を先に解く）

**この1枚が分からないと、後の数字が誤解される。省略禁止。**

メッセージ（太字）:  
**「同時アクセス」＝1日に入れる人数の上限ではない。同じ時間帯に重なってサイトを使っている人数のイメージ。**

たとえ（必ず図解・いずれかまたは併用）:

| たとえ | 説明 |
|--------|------|
| **エレベーター** | 「同時40」＝今かごに乗っている人数。1日の乗客総数ではない |
| **トイレの列** | アリーナに8,000人いても、トイレに並ぶのはその一部が「同時」 |
| **レジ** | 店に1,000人いても、レジに並んでいる人数が「同時」 |

3つの言葉を並べて対比（必須表）:

| 言葉 | 意味 | 例 |
|------|------|-----|
| **のべアクセス** | 当日どこかのタイミングでサイトを開いた人の合計 | 入場者の多くが、時間をずらして開く |
| **同時アクセス** | ほぼ同じ数十秒〜数分に重なって利用している人数 | MC「今すぐQR」で一気に重なる |
| **試験の並走数** | 負荷試験で同時進行させた仮想の閲覧（実人数と1対1ではない） | 今回は最大およそ100並走まで上げて測定 |

❌ よくある誤解（赤で×）:

- 「同時40＝1日40人までしか使えない」  
- 「入場者8,000＝今この瞬間に8,000人がサイトを見ている」  
- 「試験で100並走＝本番で必ず100人来る／来ないから大丈夫」  

✅ 正しい理解（緑で○）:

- のべは大きくても、バラバラなら同時は小さくなる  
- 一斉誘導だと、のべが小さくても同時だけ跳ねる  
- 試験は「余裕があるか」を見るもの。本番人数の予言ではない
