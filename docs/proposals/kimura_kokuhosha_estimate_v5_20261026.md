### 6.2 動く要因

| 増える | 減る |
|--------|------|
| 実物 PDF の様式が複数ある（O5 相当が初回から要る） | **ポータル DL の実物が文字 PDF のみ**（OCR 不要 → M2-2 を約 ¥105,000 減。DL したままの PDF 数件で判定） |
| CSV レイアウトが複雑（明細の多段・コード変換が多い） | レイアウトが基本情報＋詳細情報に素直 |
| 条件が多い・例外が多い（言語化シートの結果で判明） | 納期・判型・場所の少数条件で足りる |
| UPDATE／DELETE を CSV 連携に含める | INSERT のみ |
