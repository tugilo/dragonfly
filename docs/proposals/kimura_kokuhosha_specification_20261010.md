**ボタン**

| ボタン | 動き |
|--------|------|

## 4. CSV 出力（S-05）

| 項目 | 内容 |
|------|------|
| 対象 | status = approved かつ未出力。チェックで選ぶ。既定は全選択 |
| 出力 | 「CSV 出力」→ 件数確認 → 既定フォルダに書く → export_batches 記録 → draft を exported |
| ファイル名 | `ORDER_YYYYMMDD_HHMMSS_NNN.csv`（NNN は同秒の連番）。常に新規 |
| 控え | 同じ内容をサーバー内 `exports/` に保存 |
| 既定フォルダに書けない | エラー表示。draft は approved のまま。控えだけ作る＋手動ダウンロードを出す |
| 履歴 | 日時／ファイル名／件数／出力者／取込結果。行を開くと含まれる draft |
| 再出力 | 履歴から選ぶ → 新しいファイル名で再作成（取込側の同一ファイル名エラーに合わせる）。理由必須 |
| 取込結果の反映（案） | 既定フォルダに `<同名>_result.csv` があれば読む。行ごとに OK／NG を export_batch_items と draft に反映。NG は import_error に戻し、メッセージを表示 |

## 6. 製本作業予定表（S-06／S-07）

### 6.1 画面

| 要素 | 内容 |
|------|------|
| 週切替 | 先週／今週／来週／日付指定。既定は今週（月〜土。日曜は設定で） |
| 列 | 作業場所 6列: 板橋1F／1F予備／2F／2F予備／ふじみ野／ふじみ野予備（設定で増減・並び） |
| 行 | 日付。1日1行。行の高さはカード数で伸びる |
| 未配置 | 左ペイン。approved 以降の draft で、この週にカードが無いもの。希望日・納期順。検索 |
| カード | 仮番号／得意先略／書名／判型・P数／部数／希望日・配本日／作業時間。作業時間 0 は橙、入力済みは緑 |
| 合計 | マス・日・週ごとの作業時間合計。場所の稼働枠を超えたら赤 |
| 手追加 | 空欄・予備に「印刷に無い案件」をカードとして追加（draft_id null）。得意先略・書名・部数・備考 |
| 塞ぎ | マスを「使えない」にする（休み・保守）。理由メモ |
| メモ | カードの備考（見本のみ／残数等） |

### 6.2 操作

| 操作 | 動き |
|------|------|
| ドラッグ | 未配置 → マス、マス → マス。マスに入れるとき 先頭／間／末尾の差し込み位置を点線で出す |
| 入れ替え | 同じマス内の並び替え。別マスへ移動。schedule_moves に記録 |
| 作業時間 | カード上で直接入力。0.5 刻み。合計に即反映 |
| 戻す | カードを未配置へ戻す |
| 取消／やり直し | 直近 20 操作 |
| 保存 | 操作ごとに保存（自動）。週の「確定」で status = fixed。fixed 後の変更は理由付き |
| 印刷・CSV | **作らない**（第4回決定）。ブラウザの印刷は妨げない |

### 6.3 自動配置 v1（S-07）

**入力**

| 項目 | 出所 |
|------|------|
| 対象週 | 画面 |
| 未配置カード | approved 以降で未配置 |
| 配置済みカード | 現在の予定表。「固定」を付けたカードは動かさない |
| 作業場所の稼働枠 | 設定（場所×曜日の時間。既定 8h。塞ぎは 0h） |
| カードの納期 | 決定日 > 配本日 > 希望日 の順で採用 |
| 作業時間 | カードの値。未入力は「要入力」として末尾 |
| 優先度 | draft の優先度（高／通常／低。重み 設定） |
| 場所の適性 | 設定: 判型・仕様（アジロ／トライオート）ごとに使える場所（任意。無ければ全列可） |

**ルール（順に適用）**

1. 納期の早い順に並べる（同じなら優先度、同じなら部数の多い順）
2. 納期の **前営業日** までに終わる日を後ろから探す（納期ギリギリでなく、空きがあれば前倒し。前倒し上限 設定・既定 3営業日）
3. その日の、適性のある本列（予備でない）で、残り稼働枠に収まる場所に入れる。複数なら残り枠の多い場所
4. 本列に入らなければ予備列
5. どこにも入らなければ「入らない」として理由付きで一覧に出す（人が判断）
6. 作業時間未入力のカードは配置せず「要入力」に出す

**出力**

- 提案一覧: カード／提案 日付・場所・位置／理由（納期・優先度・空き）
- 予定表の見比べ: 現在と提案を左右に。動くカードを色で（新規 緑、移動 黄、入らない 赤）
- ボタン: 確定（反映して auto_plan_runs に confirmed）／取消／カード単位で採用・不採用

**記録**

- 提案 JSON、確定の有無、確定後 1週間以内の人の入れ替え（was_auto_proposed = true の move）を残す
- 月1回、「提案どおり」「人が直した」の割合を出す（並行テストの材料。画面は簡易表）

**v2（あれば便利 O3）:** 前後工程の生産性指標（場所×判型×仕様ごとの実績 h／1000部）、理由の詳細、重みの調整画面。
