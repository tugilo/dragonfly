## 1. 結論

作る Web は1つ。人が使う機能は **2つ**。基幹（VB + Oracle）には手を入れません。

| 機能 | 一文 |
|------|------|
| **1. 注文入力** | 注文書PDF をまとめて上げる → 項目ごとの欄に抜き出す → 人が1件ずつ直して承認 → **CSV に出す** → 既存システム側の取込プログラムが Oracle に入れる |
| **2. 製本作業予定表** | いま Excel を印刷してペンで組んでいる週次の予定表を、同じ並びの画面にする。手で置く操作に加えて、**自動配置ボタン**（ルールで組む。人が確定） |

**第4回で変わった点（3つ）**

1. **Oracle へ直接書き込まない。** こちらの DB に仮登録 → CSV 出力 → 既存システムの取込プログラムで Oracle へ。取込プログラムは既存システムの開発会社が作る（2026-09-29 打合せ資料）。
2. **自動配置を入れる。** AI ではなくルール（納期・作業時間・優先度・場所の空き）で順番を提案し、人が確定する。
3. **メール添付の生産依頼表（Excel）は、まず手で入力する画面から。** 自動取り込みは段階的に。

## 3. 機能1 — 注文入力

### 3.1 流れ

```text
[注文書PDF（メール添付）]
  → まとめてドラッグ＆ドロップ
  → 1件ずつ解析し、項目の欄に抜き出す
  → 人が欄を直す（必ず人が見る）
  → 「承認」で補助DBに登録（仮番号）
  → 「次へ」で次のPDFの解析が始まる
  → 承認済みを CSV に出力（既定フォルダ）
  → 既存システムの取込プログラムが Oracle へ（手動実行・既存システム側）
```

### 3.2 対象

- 最初は **型の揃った主要1社** の PDF。他社フォーマットは後から足す
- PDF 以外の注文（メール添付の生産依頼表 Excel）は **手動入力画面**で同じ補助DBに登録 → 同じ CSV へ

### 3.3 やらないこと

- 100%自動登録。人が1件ずつ承認する
- Oracle への直接書き込み。Oracle にテーブルも足さない
- 手書き注文書の OCR

## 4. 機能2 — 製本作業予定表

### 4.1 画面

- 縦に日付（週）、横に作業場所（板橋1F／1F予備／2F／2F予備／ふじみ野／ふじみ野予備）
- 左に **未配置**（機能1で承認した注文、手動入力した生産依頼表）
- 未配置から日付×場所のマスへドラッグ。先頭・間・末尾の差し込み位置を出す
- カードに **作業時間** を入れる（最初は0。入れると橙→緑）。マス・日・週の合計を出す
- 印刷に無い注文の手追加、枠の塞ぎ、入れ替え

### 4.2 自動配置

- **「自動配置」ボタン**で、未配置と配置済みを、ルールに沿って並べ直して **提案**する
- ルール v1: 納期（決定日・配本日）、作業時間、優先度、場所の空き。前後工程の生産性指標は v2 以降
- 人が **確定**を押すまで反映しない。人が入れ替えた内容は記録し、ルールの見直しに使う
- 検証は **1月の並行テスト**で、現行の手組みと並べて比べ、合うまで直す

### 4.3 やらないこと（第4回で決定）

- 予定表の CSV 出力・印刷機能。画面で結果が見えれば足りる
- 順番の自動確定
- AI による配置（API を使う拡張は将来の選択肢として残す）

## 5. つながりと置き場所

```text
[ブラウザ（社内）]
    ↓
[Web アプリ（Docker）]  ← 機能1・機能2・ユーザー・ログ
    ↓ 補助DB（MariaDB）に仮登録・証跡・予定表
    ↓ CSV 出力（既定フォルダ・ファイル名は一意）
[取込プログラム（既存システム開発会社）]  ← 手動実行
    ↓
[Oracle（受注の正・既存）]  ← VB もこれまでどおり
```

- 置き場所は **社内**。既存 Windows の Hyper-V 上 Ubuntu、または **専用PC（16GB・SSD）** のどちらか。外には出さない。Google Workspace / GAS は使わない
- 補助DB は **正にしない**。受注・得意先・注文番号の正は Oracle のまま
- 詳しくは [システム構成図](kimura_kokuhosha_system_architecture_20261010.md)

## 9. 判断の目安（ROI・試算）

木村さん申告の時間を使った試算です。削減率・回収年数の保証ではありません。

- 手入力 1日1.5時間 ＋ 予定組み 1日2時間 ＝ **1日3.5時間**。月20日で **70時間/月、840時間/年**
- 削減率 50% なら 420時間/年、70% なら 588時間/年
- 人件費を仮に ¥2,500/時間 とすると、年 105万〜147万円相当

必須合計（サーバー込み）に対する回収の目安は見積 §6。実測は1月の並行テストで置き換えます。
