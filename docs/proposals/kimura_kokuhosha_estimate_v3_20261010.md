## 1. 前提

| 項目 | 内容 |
|------|------|
| 基幹 | VB + Oracle は触らない。テーブルも足さない |
| 連携 | 補助DB → **CSV 出力** → 既存システム開発会社の取込プログラム → Oracle。レイアウトは開発会社が設計 |
| 対象PDF | 最初は **主要1社・1フォーマット** |
| 生産依頼表 | メール添付 Excel。**手動入力画面**から（必須）。アップロード読込・メール自動取込は「あれば便利」 |
| 予定表 | 6列（板橋1F／1F予備／2F／2F予備／ふじみ野／ふじみ野予備）×日付。CSV 出力・印刷は **作らない** |
| 自動配置 | **ルールベース v1**。人が確定。AI API は「あれば便利」 |
| 置き場所 | 社内（既存 Hyper-V 上 Ubuntu または専用PC）。Docker。外部公開なし |
| 補助DB | MariaDB（PostgreSQL も可）。正は Oracle |
| 利用者 | 事務・予定組み担当・管理者。少人数 |
| 日程 | 10〜12月開発、1月並行テスト、2月検収 |

## 7. 金額が動く要因

| 増える | 減る |
|--------|------|
| CSV レイアウトが複雑（明細の多段・コード変換が多い） | レイアウトが生産依頼表に近い |
| 主要1社の PDF に表の崩れ・複数ページが多い | 1ページ固定で表が揃っている |
| 自動配置の条件が多い・例外が多い | 納期と時間だけで足りる |
| Hyper-V の空きが足りず専用PC 新規購入 | 既存 Hyper-V に 4vCPU／8GB／80GB が取れる |
| UPDATE／DELETE を CSV 連携に含める | INSERT のみ（修正は VB 側） |
