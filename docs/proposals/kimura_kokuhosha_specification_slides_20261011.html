8. 自動配置 v1（S-07）

入力 → 6つのルール → 提案 → 人が確定

入力

  • 対象週、未配置、配置済み（「固定」は動かさない）
  • 作業場所の稼働枠（場所×曜日。既定 8h。塞ぎは 0h）
  • 納期: 決定日 ＞ 配本日 ＞ 希望日 の順で採用
  • 作業時間（未入力は「要入力」）
  • 優先度（高／通常／低。重み設定）
  • 場所の適性（判型・仕様ごと。任意）

ルール（順に適用）

  1. 納期の早い順（同じなら優先度、同じなら部数の多い順）
  2. 納期の前営業日までに終わる日を後ろから探す。空きがあれば前倒し（上限 既定 3営業日）
  3. その日の、適性のある本列で、残り稼働枠に収まる場所へ。複数なら残り枠の多い場所
  4. 本列に入らなければ予備列
  5. どこにも入らなければ「入らない」として理由付きで一覧へ（人が判断）
  6. 作業時間未入力は配置せず「要入力」に

出力・確定・記録

  • 提案一覧: カード／日付・場所・位置／理由
  • 見比べ: 現在と提案を左右に。新規 緑、移動 黄、入らない 赤
  • ボタン: 確定／取消／カード単位で採用・不採用
  • 提案 JSON、確定の有無、確定後1週間の人の入れ替えを記録
  • 月1回「提案どおり」「人が直した」の割合を出す

O3v2: 生産性指標（場所×判型×仕様の実績 h／1000部）、理由の詳細、重みの調整画面
