- 幹になる機能から始め、「あったらいいな」はあとから足す

## 2. 共有いただいたExcelを確認してわかったこと

- 見積書作成システム・月次請求書作成ツール・売上台帳作成ツール・ボディーマスタの4本を確認しました。長年かけて作り込まれた、**よくできた業務システム**です。
- **加工料金は、すでに料金表マスタから自動で計算されています**（シルク・DTF・刺繍・インクジェット、サイズ×枚数帯）。この計算の考え方は、新しいシステムにそのまま引き継ぎます。
- 一方で、月次請求と売上台帳は「ファイル名の日付」「決まったセルの位置」「フォルダに集めたファイル」を頼りに動いています。ファイルの置き場所や名前がずれると集計が合わなくなるため、**データとして一か所にまとめる効果が大きい部分**です。
- ボディーマスタはメーカー名の表記ゆれがあるため、移行時に整理します。

## 3. 新しい仕組みでこう変わります

| 場面 | いま | これから |
|------|------|----------|
| 注文 | 自由入力のフォーム。ログインなし | お客様ごとにログイン。ボディは検索しながら選ぶだけ。存在しない品番は選べない |
| 見積 | PDFを見てExcelに手入力 | 注文内容がそのまま見積になる。ボディ代は自動、加工は選ぶと単価が出る |
| お客様とのやり取り | 進み具合は都度LINEで確認 | お客様がマイページで「いまどこまで進んでいるか」を確認できる |
| 再注文 | もう一度フォームに全部入力 | 過去の注文から「同じ内容で注文」→ 枚数を変えるだけ |
| ボディーマスタ | Excelで手作業 | 管理画面から追加・廃番・価格改定。CSVでまとめて取込 |
| 月次請求・売上台帳 | ファイルを集めてマクロで集計 | 月を選んでボタンを押すと、法人は月次でまとめて請求書。売上台帳もそのまま出力 |
| 発注・送り状（オプション） | 手で作成 | 注文データからメーカー発注CSV・ヤマト送り状CSVを出力 |
