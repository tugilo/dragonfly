## 先に結論（これだけ覚えれば大丈夫）

お金は **3つ** に分かれます。アプリを作る会社への支払いは、この数字に **入っていません**。

1. **最初だけ** — 次廣がサーバーを用意する費用 → **38万円前後**
2. **毎月 Amazon へ** — サーバーの家賃 → **3〜6万円**（目安 4万円）
3. **毎月 次廣へ（任意）** — サーバーが動いている状態を保つだけ → **1〜2万円**（頼まなければ 0円）

画面・機能の不具合対応はできない。それは開発会社。

会話用:  
「サーバーの準備が税別38万前後。Amazonへの家賃がテスト用と本番で月3〜6万。保守は、サーバーが動いている状態を保つだけなら月1〜2万。システムの中身は対応できません。」

## たとえ（倉庫に例える）

足場を置く倉庫と同じです。

| 倉庫の話 | 今回の話 |
|----------|----------|
| 倉庫の建物・電気・鍵 | サーバー（次廣が用意する） |
| 中の棚の並べ方、伝票の仕組み | システム（別の会社が作る） |
| 本番の倉庫 | **本番**（現場や倉庫が本当に使う） |
| 練習用の空き倉庫 | **テスト**（壊しても本番が止まらない） |
| 倉庫の家賃 | **毎月 Amazon に払うお金** |
| 倉庫を建てる工務店 | **次廣の最初の費用** |
| 倉庫の見回りを頼む | **次廣の月額（任意）** |

テスト用がないと、改修の練習が本番倉庫の中になります。おすすめしません。

Amazon（AWS）は、自分で倉庫を買わず、**必要な広さだけ毎月借りる**サービスです。電気代のように、使った分が請求されます。

## 3つの選び方

| | **小さめ** | **ふつう（おすすめ）** | **厚め** |
|--|------------|------------------------|----------|
| イメージ | とりあえず店を開ける | 倉庫が止まると現場が困る | 絶対に止められない |
| 最初（次廣） | 28万円 | **38万円** | 58万円 |
| 毎月 Amazon | 1.5〜2.5万円 | **3〜6万円** | 8〜15万円 |
| サーバー保守（次廣・任意） | なし | **月1〜2万円** | **月1〜2万円**（夜間対応は含まない） |
| 向くとき | 社内の数人、日中だけ | 出庫が止まると困る、写真も置く | 夜中も現場、お客様向けサイトもある |
| 我慢すること | 不具合が出ると、店全体が一緒に止まる | 本番直前用の3つ目の部屋はない | 毎月が高い |

まずは **ふつう** で考えます。  
「安く始めたい。半日止まっても現場は回る」とご自身で言えるときだけ、小さめにします。

## 最初の38万円で何をするか

家を建てるときの「設計〜鍵渡し」です。

| | 何をするか | たとえ | 金額 |
|--|------------|--------|------|
| 1 | ご要望の確認、間取りを決める | 設計図 | 5万円 |
| 2 | 契約、鍵の管理、火事にならない配線 | 基礎と鍵 | 8万円 |
| 3 | 本番の部屋を用意する | 本番倉庫 | 12万円 |
| 4 | テスト用の小さい部屋を用意する | 練習倉庫 | 8万円 |
| 5 | 使い方を渡す、開発会社へ説明 | 鍵渡し | 5万円 |
| | **合計** | | **38万円** |

テスト部屋を作らないと 30万円になります。開発会社が本番で試すことになるので、おすすめしません。

**足せるもの**

- 異常が起きたときの見方・連絡先の整理 → ＋12万円
- 本番直前だけ使う3つ目の部屋 → ＋10万円
- 打合せが2回を超える分 → 1回 2万円

## サーバー保守（毎月・頼むかどうか）

サーバーを渡したあと、次廣が見なくても構いません。その場合、あとからの更新や不具合は竹村さんか開発会社の担当です。

| | 内容 | 毎月 |
|--|------|------|
| 見ない | 渡したら終わり | 0円 |
| 基本保守 | 稼働確認、容量、バックアップ、SSL証明書など、サーバーが動く状態を維持 | **1〜2万円** |

画面がおかしい、計算が違う → **開発会社**  
サーバーが落ちた、容量がいっぱい、鍵の期限切れ → **次廣**（保守を頼んだ場合）

プログラムの調査・修正、画面・機能・データ内容への対応、夜間休日の即時対応は基本保守に含みません。この切り分けは書面に残します。

---

## 毎月 Amazon に払う家賃

AWSなどのアカウント作成・初期設定はこちらで行う想定です。契約名義と支払い方法は、正式見積時に確認します。サーバー利用料は構築費・保守費とは別の実費です。

| 部屋 | 何のため | 毎月の目安 |
|------|----------|------------|
| 本番 | 現場や倉庫が本当に使う | 2.0〜3.5万円 |
| テスト | 改修の練習。本番を止めない | 0.8〜1.5万円 |
| 共通 | 住所（ドメイン）、控え、記録 | 0.3〜1.0万円 |
| **合計** | | **3〜6万円** |

テスト部屋は、夜や休日に電気を落とすと、その分はだいたい半分以下になります（部屋そのものの保管料は残ります）。開発会社が毎日触るならつけっぱなし。週に数回なら消してよいことが多いです。

**この金額に入っていないもの**

- 画面や機能を作る会社への支払い
- ホームページの住所（ドメイン）本体。年 1,500〜3,000円くらいが多い
- システム側の調査・修正
- 夜間休日の即時対応

## システム会社への質問事項

竹村さんには、この質問をシステム会社へ転送していただきます。回答をもとに、AWSまたはXServer等の適切な環境を選び、正式見積を出します。

### 必要な環境

- 本番環境とテスト環境の両方が必要ですか。
- AWSを希望しますか。XServerなどでも対応可能ですか。
- 必要なOSは何ですか。
- 使用するプログラム言語・フレームワークと、それぞれのバージョンは何ですか。
- 使用するデータベースの種類とバージョンは何ですか。

### サーバーの大きさ

- 必要なCPU、メモリ、保存容量を教えてください。
- 想定利用者数と最大同時アクセス数を教えてください。
- 画像やPDFなどのファイルを保存しますか。想定容量はどの程度ですか。

### ドメイン・通信

- 独自ドメインとSSLは必要ですか。
- システムからメールを送信しますか。
- 外部サービスとの連携はありますか。
- IPアドレス制限やVPNは必要ですか。

### バックアップ・監視

- バックアップの頻度と保存期間を教えてください。
- サーバー監視と異常時の通知は必要ですか。
- ログの保存期間を教えてください。

### 作業分担

- システムをサーバーへ設置する作業は、システム会社が行いますか。
- システムの更新と公開後のシステム保守は、システム会社が行いますか。
- インフラ担当に必要な作業範囲を教えてください。

### スケジュール

- テスト環境はいつまでに必要ですか。
- 本番環境はいつまでに必要ですか。
- 公開予定日はいつですか。
