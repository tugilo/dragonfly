## 1. 何が変わるか

| | v3（10/12 お渡し） | 変更後（v4 で反映） |
|---|---|---|
| 自動配置の方式 | **ルールのみ**で順番を提案。AI は「あれば便利 O4」（将来の選択肢） | **ルール＋AI**。ルールが納期・稼働枠などの制約を守り、**AI が順番の案と理由を出す**。言葉での指示（「A社を来週に前倒し」）でも組み直せる |
| 確定するのは | 人 | 人（変わらず） |
| AI が止まったとき | — | ルールだけの提案に自動で切り替わる。従来の手組みにも戻れる |
| 外部への通信 | なし（社内 LAN のみ） | **AI API への外向き通信のみ**追加。渡すのは注文ID・判型・数量・納期・所要時間・優先度・空き状況。**得意先名・担当者名・金額・PDF 原本は渡さない**（ID に置換） |
| AI サービス | — | OpenAI API または Anthropic API（Gemini も可）。**契約名義は国宝社様**。API 経由の入力は学習に使われない設定 |

経緯: 10/5 の打合せでは「まずルールで組み、AI は将来」としましたが、木村様より **予定表で AI を活用したい**とのご意向を伺い、見直しました。助成金申請時のご説明（生成 AI の活用）とも整合します。
