## 0. 結論（提案に効くポイント）

1. **加工料金は、すでにExcelの数式で自動計算されている。** 社内の担当者が「加工方法・サイズ・版数・色変え数・数量」を選ぶと、`料金表マスタ` から単価を引いて金額を出している。9/7に「対象外」とした加工料金の自動計算は、**お客様の入稿画像から加工内容を自動で判定すること**と読むのが正しい。料金表で単価を引く部分は、新システムの見積機能（基本パッケージ #5）に **含めるべき**。
2. **粗利・経費も数式で自動計算されている。** 加工方法ごとに粗利率ルールがある（§1.4）。その結果を見積書の `B1`（「弊社管理No.WB…」）に文字列として埋め込み、月次請求ツールと売上台帳ツールがそこから粗利を読み戻している。新システムでは明細ごとに粗利を持てば、この仕組みは不要になる。
3. **月次請求と売上台帳は、ファイル名・セル番地・フォルダ構成に依存している。** ファイル名の先頭8文字を日付として使い、セル番地は設定表で固定し、フォルダ内のファイルを走査している。1ファイルでも規約から外れると集計が崩れる。DB化すれば、これらの依存はすべてなくなる。
4. **ボディーマスタはメーカー名の表記ゆれが大きい。** 8,089行・266品番に対してメーカー表記が34種類あり、同じメーカーが別名で重複している（例: Printstar／プリントスター／PRINT STAR／PRINTSTAR）。データ移行時の名寄せ作業を見積に入れる必要がある。

### 1.3 加工料金の計算（数式）

担当者は `入力用` の加工行で **加工方法・サイズ・位置・版数・色変え数・数量** を入れる。単価と版代は数式で自動計算される。

| 加工方法 | 版代・データ代 | プリント単価 |
|----------|----------------|--------------|
| シルクスクリーン | サイズ別（5段階：1,480〜3,780円）× 版数 | サイズ（5段階）× 数量帯（1/5/15/30/50/80/120/200枚以上）の単価表から、**1色目の単価＋（版数−1）×2色目以降の単価** |
| DTF | なし | サイズ（4段階）× 数量帯（1/5/15/30/50/80/100枚以上） |
| 刺繍 | サイズ別データ代（4段階：1,480〜3,980円） | サイズ別の固定単価（数量で変わらない） |
| インクジェット | なし | サイズ（5段階）× 数量帯（1/11/21/51/81枚以上） |

- 数量帯は「その枚数以上」で引く（`MATCH` の近似一致）。
- オプション（タグ加工、素材追加料金、特殊インク、OPP袋詰め、持ち込み料金など約30種）は、単価が入力用シートに直書きで、数量を入れるだけで計算される。
- **確認事項:** インクジェットの 15×15cm は「1〜10枚: 550円」「11〜20枚: 580円」で、枚数が多いほど高くなっている。入力ミスの可能性がある。

### 1.4 合計・粗利の計算（見積書テンプレの数式）

| 項目 | 計算 |
|------|------|
| お買上額 | 明細金額の合計 |
| WEB割 | −ROUND(お買上額 × 割引率%)（既定3%） |
| 消費税 | ROUND((お買上額＋送料＋代引手数料＋WEB割) × 税率) |
| 請求金額 | お買上額＋送料＋代引手数料＋WEB割＋消費税 |

明細ごとの粗利・経費のルールは次のとおり。

| 明細の種類 | 粗利 | 経費 |
|------------|------|------|
| シルクスクリーンのプリント代 | 金額の90% | 10% |
| DTFのプリント代 | 1枚あたり300円 | 残り |
| インクジェット | 金額の10% | 90% |
| 版代・データ代・オプション | 金額の100% | なし |
| ボディー | 金額 − 金額/1.2 | 金額/1.2（＝下代） |

- 見積書の `B1` に `弊社管理No.WB{粗利合計6桁}-{粗利率3桁}` を出している。月次請求と売上台帳はこの文字列を分解して粗利を得ている。
- 名前定義 `値引き率` は参照切れ（`#REF!`）になっている。使われていない名残とみられる。
- 会社情報（住所・登録番号・電話・メール）はテンプレに直書きされている。

## 6. ChatGPT解析との照合（2026-09-27 21:50 JST）

ユーザーがChatGPTで同じ4ファイルを解析した結果を共有。全体像（マスタ → 見積 → 月次請求 → 売上台帳のファイル連携）と、Web化で推奨された実装順（①商品・加工料金マスタ ②見積／受注とPDF ③納品・請求・領収書 ④月次締めと売上台帳）は本書と一致する。

### 6.1 ChatGPTにあり本書になかった指摘（コードで確認済み）

| 指摘 | 確認結果 | 新システムでの扱い |
|------|----------|-------------------|
| 注文書の帳票はない | 正しい。出せるのは見積書・納品書・請求書・領収書のみ | 注文フォームからの受注を「受注ステータス」として持つ。注文書（注文請書）PDFが必要かは粕谷さんに確認 |
